# Caption templates

Rules for every platform: `#ad` first, one CTA, one destination, honest claims only, Associates statement where space allows, no prices or deals.

Variables: `{HOOK}` `{BENEFIT}` `{PRODUCT}` `{LINK}` = `https://www.amazon.com/dp/{ASIN}?tag=YOUR_TAG-20` `{HASHTAGS}` (2 to 5, niche-specific).

Disclosure line: `#ad · As an Amazon Associate I earn from qualifying purchases.`

## X (max 280; a URL counts as 23)
```
#ad {HOOK} {PRODUCT} - {BENEFIT}.
Find it on Amazon: {LINK} {HASHTAGS}
```

## Threads (max 500)
```
{HOOK}
For: <who it is for>
Not for: <who should skip it>
{PRODUCT} - {BENEFIT}. Find it on Amazon.
#ad · As an Amazon Associate I earn from qualifying purchases.
{LINK}
```

## Pinterest
```
Title (max 100):  {Problem keywords} - {PRODUCT}
Description:      {BENEFIT}. {Who it is for}. Find it on Amazon.
                  #ad · As an Amazon Associate I earn from qualifying purchases. {HASHTAGS}
Link:             {LINK}
Board:            <niche board name>
```

## Instagram / TikTok
Many accounts cannot use clickable links in captions. Point to the bio link or your landing page.
```
#ad {HOOK}
{PRODUCT} - {BENEFIT}.
Link in bio (YOUR_HANDLE). As an Amazon Associate I earn from qualifying purchases.
{HASHTAGS}
```

## Never write
- Prices, "Prime", "% off", "deal", "sale", "today only", "limited time", "lowest price", "selling out"
- "Best ever", "cures", "guaranteed", made-up review or customer counts
- Another creator's wording, handle or overlay
